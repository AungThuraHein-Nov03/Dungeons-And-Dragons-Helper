# Eldritch Knight Spell Reference — 2024 Rules

For: D&D 3.0 / Renethal reference
Audit date: 2026-09-20

## Core rule

The 2024 Eldritch Knight chooses spells from the **Wizard spell list**. The old 2014 restriction that pushed most choices toward Abjuration/Evocation is gone. When an Eldritch Knight gains or replaces a prepared spell, the spell can be any Wizard spell for which the character has spell slots.

Eldritch Knight spellcasting tops out at **4th-level spells**, so the complete relevant 2024 PHB Wizard pool is the cantrip-through-level-4 list below.

## Legend

- **SRD** — spell is in SRD 5.2.1, sometimes under a generic renamed equivalent.
- **PHB-only** — spell appears in the 2024 Player's Handbook Wizard list but is not part of SRD 5.2.1.
- **SRD alias** — PHB uses a branded/name-character version while SRD uses a generic equivalent.

## Legacy / campaign-compatible spells

The list above is the **2024 Player's Handbook Wizard list**. Older compatible sourcebooks can add more Wizard spells if the campaign allows legacy content.

- **Booming Blade** — legacy Wizard cantrip; not a 2024 PHB spell. Renethal already knows/uses it in this campaign, so it is an explicit campaign allowance.

Do not silently mix legacy spells into the 2024 PHB list. Keep them tagged by source so the ruleset boundary stays obvious.

## Renethal quick reference

At Fighter 4, Renethal can currently select only **Wizard cantrips and level 1 Wizard spells** from the 2024 list, plus any explicit legacy spells the campaign has allowed.

If he multiclasses before Fighter 7, his Eldritch Knight subclass still does **not** unlock level 2 Wizard spells until he reaches **Fighter 7**. Character level and Fighter level are not interchangeable for subclass feature unlocks.
